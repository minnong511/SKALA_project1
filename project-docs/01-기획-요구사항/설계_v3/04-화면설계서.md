### 2. 화면 와이어프레임

```text

+----------------------------------+
```

### 3. 사용자 흐름

1. [01] 이메일 가입: 화면 진입 시 CSRF를 발급한다. 필수값 검증 후 가입하고 로그인 탭으로 이동한다. 중복 이메일은 입력란에 표시한다.
2. [02] 이메일 로그인: CSRF 발급 → 로그인 → 토큰 재발급 → 현재 사용자 조회 순으로 처리한다. role=ADMIN이면 관리 화면, USER이며 설문 미완료이면 설문, 완료이면 홈으로 이동한다.
3. [03] 구글 로그인: CSRF 발급과 구글 인증 후 ID 토큰을 제출한다. 성공 후 CSRF를 재발급하고 사용자 상태를 확인한다. role=ADMIN이면 관리 화면, USER이며 설문 미완료이면 설문, 완료이면 홈으로 이동한다.
4. [04] 입력과 오류 안내: 이메일, 비밀번호, 표시 이름 입력. 누락된 필수값이 있으면 실행 버튼 비활성화.
