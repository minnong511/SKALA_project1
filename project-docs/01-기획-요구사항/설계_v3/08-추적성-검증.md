## 검증 경계

이번 검증은 현재 v2와 문서의 의미 대조, YAML 및 예시 구조, 추적성, DDL 텍스트 검사와 평점 규칙의 고정 사례 계산이다. 공식 OpenAPI 전체 스키마 검사, Swagger Editor 화면 실행, PostgreSQL에서 SQL 실행, 실제 LLM 판정 정확도와 동시성 테스트는 수행하지 않았다.

## 남은 확인 사항

AI 모델과 비교 지침, 동시 신규 메뉴 중복 방지, 인증 구현 방식과 영수증 유효 시간, 파일과 본문 제한, 홈 추천과 인기순 기준, 챗봇 문맥, 관리자 연결 데이터 삭제 정책은 1단계의 확인 사항으로 남긴다. 미정 사항을 v2에서 확정된 정책처럼 취급하지 않는다.
