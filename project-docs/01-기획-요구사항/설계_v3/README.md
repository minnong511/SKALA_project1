## 적용 기준

동일 메뉴는 등록 API 내부의 LLM 판정으로 자동 연결한다. 메뉴 평점은 사용자별 현재 후기 평균을 다시 평균낸다. 추가 재료만 관리하고, 대표 사진이 삭제되면 주소를 NULL로 비워 기본 이미지를 표시한다.

인증과 파일 제한 등 구현 제안은 1단계의 [확인 필요] 항목이다. v3 폴더 밖의 이전 API/DBML/ERD 이미지는 이번 수정 대상이 아니므로 혼용하지 않는다. SQL은 신규 스키마 생성용이며 DB 마이그레이션을 실행한 것은 아니다.

문서 의미 대조와 정적 검증을 완료했다. 실제 DB 실행과 Swagger UI, LLM 연동 검증은 수행하지 않았다.
